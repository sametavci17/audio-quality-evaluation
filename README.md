# Audio Quality Evaluation

A small personal learning project for practicing structured evaluation of AI-generated audio.

## What it evaluates

The interface scores audio using six criteria:

- Clarity
- Naturalness
- Background noise
- Distortion / artifacts
- Pronunciation
- Overall quality

Each criterion is rated from 1 to 5. The application calculates an average score and gives a simple interpretation.

## Purpose

This project was created as a learning exercise related to AI data evaluation, audio quality assessment and basic web development.

It is not a professional audio certification tool and does not automatically analyze an audio file.

## Technologies

- HTML
- CSS
- JavaScript

## Learning goals

- Build a simple evaluation workflow
- Practice structured quality assessment
- Create a clear scoring system
- Practice basic front-end development
